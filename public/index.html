Recruiter's Technical Architecture

This is not a wrapper — it's a full-duplex, voice-native RAG system. Every badge below maps to a real production module you can grep in the codebase.

Backend

FastAPI Async WebSockets

`app/main.py` composition root + `app/presentation/websockets/stream.py` — persistent `WS /ws/stream` with `BackgroundTasks` summary worker.

Streaming

Native 16kHz PCM Upstream Proxy

`AudioWorklet → PCM16` 100ms chunks → base64 → `client.aio.live.connect` bidi. Ordered `AudioContext` playback queue.

AI Engine

Gemini Live LiveConnectConfig API

`google-genai` `LiveConnectConfig(speech_config=Aoede/Charon, system_instruction as custom_ai_name)` — single model `gemini-2.0-flash-live-preview-04-09`, no candidate loop.

Vector Engine

LangChain + pgvector Retrieval / Hybrid Semantic Store

`RecursiveCharacterTextSplitter` + `text-embedding-3-small` → `pgvector vector(1536)` or in-memory cosine fallback.

Database

Dynamic SQLite (Dev) / PostgreSQL Asyncpg (Production)

`app/core/database.py` — `DATABASE_URL` switch: `sqlite+aiosqlite` local file vs `postgresql+asyncpg` on Render, `User` table with `bcrypt`.

Observability

OpenInference Tracing via Arize Phoenix Cloud

`phoenix.otel.register(protocol="grpc", headers={"api_key": ...})` + `OpenAIInstrumentor` — fixes `405` via gRPC.
